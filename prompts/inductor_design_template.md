# Техническое задание на расчёт силового ВЧ-дросселя

Заполнить значения `<…>`, сохранить как `2_input_files/prompt.txt`, перенести числа в `design_config.json` и запустить навык `knowledge_base/skills/inductor-design`.

## 1. Расчётная схема

Тип: `<один boost-дроссель / N-фазный interleaved boost с отдельным дросселем каждой фазы>`.

Режим: `CCM — непрерывный ток`.

Число фаз для interleaved: `<2 / 3 / 4 / N>`.

Магнитная архитектура: `отдельный магнитопровод и отдельная обмотка каждой фазы`.

Текущий движок не применяется к buck, buck-boost, BCM, DCM, связанным дросселям и общему магнитопроводу нескольких фаз без отдельного расширения методики и кода.

## 2. Электрические исходные данные

| Параметр | Значение |
|---|---:|
| Входное напряжение `U_вх`, В | `<160>` |
| Допуск или диапазон `U_вх`, % | `<±5>` |
| Выходное напряжение `U_вых`, В | `<235>` |
| Выходной ток `I_вых`, А | `<25>` |
| Выходная мощность `P_вых`, Вт | `<6000>` |
| Правило при `P_вых ≠ U_вых · I_вых` | `<приоритет мощности / приоритет тока / считать оба угла>` |
| Коэффициент полезного действия `η`, % | `<90>` |
| Частоты коммутации `f_sw`, кГц | `<100; 150>` |
| Размах пульсации фазного тока, % | `<10>` |
| Пульсации входного и выходного напряжения, % | `<10>` |
| Перегрузка по току, % | `<+10>` |
| Неравномерность токов фаз, % | `<±2>` |
| Допуск индуктивности, % | `<±10>` |

Частотные варианты считать независимыми конструкциями и не суммировать в спецификации.

## 3. Тепловые и конструктивные ограничения

| Параметр | Значение |
|---|---:|
| Температура среды, °С | `<40>` |
| Допустимый перегрев обмотки, К | `<60>` |
| Максимальная температура сердечника, °С | `<100>` |
| Предварительная плотность тока `J_пред`, А/мм² | `<2,5>` |
| Предельная плотность тока `J_max`, А/мм² | `<2,5>` |
| Допустимое заполнение медью `k_м`, отн. ед. | `<0,35>` |
| Допустимая занятость окна `k_зан`, отн. ед. | `<0,70>` |
| Исполнение зазора | `ОДИН физический зазор центрального стержня` |
| Минимальный отступ меди от кромки зазора, мм | `<5>` |
| Ограничение габаритов | `<нет / A × B × C мм>` |
| Ограничение массы | `<нет / кг>` |

Зазор задавать через целевой `A_L`. Размер `g` считать оценкой до метода конечных элементов (МКЭ) и доводки по измерению.

## 4. Магнитные и резонансные запасы

| Критерий | Значение |
|---|---:|
| Предварительный коэффициент `k_B,пред` | `<0,60>` |
| Финальный коэффициент `k_B` | `<0,65>` |
| Численная погрешность `u_B` | `не задавать до исследования сеточной сходимости МКЭ` |
| Минимум `k_R = ℛ_g/ℛ_c = A_L0/A_L − 1` | `<4>` |
| Запас первого резонанса `k_f` | `<3>` |
| Верхняя требуемая частота модели | `<5 · f_sw>` |
| Запас по электромагнитной совместимости, дБ | `<6>` |

`k_R` не является отношением частот. Для резонанса используется отдельный коэффициент `k_f`.

## 5. Компоненты и политика выбора

Предпочтительные семейства: `EQ`, `ETD`, `PM`, `PQ`, `RM`, `EER`.

Резервное семейство: `E`, только если после полного численного перебора `preferred_feasible = 0`.

Перебрать все полностью описанные сочетания:

`сердечник × материал × литцендрат × параллельные провода × число витков`.

Для каждой пары сердечник–материал привести количество рассчитанных и допустимых вариантов, лучший вариант или ближайший отклонённый вариант и численную причину отказа.

Если предпочтительный типоразмер из `screened_out` проходит предварительный отсев, догрузить официальный даташит и полные параметры в базу до выбора E. Разрешённые или запрещённые марки: `<перечень / нет>`.

## 7. Результаты

Сформировать:

- расчётный JSON с полным снимком ТЗ;
- рисунки схемы, укладки, форм тока и импеданса;
- `.docx` по ГОСТ Р 2.105—2019 в структуре из 13 разделов эталонного отчёта;
- численное сравнение всех подходящих вариантов;
- спецификацию количества: один дроссель — один комплект и две половинки; `N` независимых фаз — `N` комплектов и `2 · N` половинок;
- перечень незакрытых МКЭ, тепловых, резонансных и ЭМС-проверок.

До появления реальных артефактов МКЭ и испытаний статус результата — только `analytical_preliminary`.
