## 1. Задача

Необходимо рассчитать дроссель `<однофазного boost / трёхфазного interleaved boost /
N-фазного interleaved boost / buck / другое>` преобразователя.

Число фаз: `<1 / 2 / 3 / 4>`
Режим работы: `<CCM (непрерывный ток) / BCM (граничный) / DCM (прерывистый)>`

## 2. Исходные данные

| Параметр | Значение |
|---|---|
| Входное напряжение U_вх | `<160>` В |
| Выходное напряжение U_вых | `<235>` В |
| Выходной ток I_вых | `<25>` А |
| Выходная мощность P_вых | `<6000>` Вт |
| КПД η | `<90>` % |
| Частота коммутации f_sw | `<100 или 150>` кГц |
| Пульсации тока в дросселе ΔI/I | `<10>` % |
| Пульсации входного напряжения | `<10>` % |
| Пульсации выходного напряжения | `<10>` % |
| Температура окружающей среды | `<40>` °C |
| Допустимый перегрев обмотки | `<60>` K |

Если под обе частоты одновременно оптимизировать не удаётся — привести два варианта расчёта.

## 3. Конструктивные требования

Предпочтительная форма магнитопровода: `<PM, PQ, EQ, ETD, RM, EER — с круглым центральным
стержнем; E-сердечник как крайний вариант>`

Исполнение зазора: `<ОДИН зазор в центральной части / распределённый на несколько участков /
без ограничений>`

Провод обмотки: `<литцендрат, доступный к покупке на территории РФ / без ограничений>`

Ограничения по габаритам: `<нет / не более AxBxC мм>`
Ограничение по массе: `<нет / не более X кг>`

## 4. Нормативные требования и запасы

| Критерий | Значение |
|---|---|
| Нормативный документ по ЭМС | `<ГОСТ 30805.22 класс B / CISPR 11 / нет>` |
| Запас по ЭМС M_ЭМС | `<6>` дБ |
| Коэффициент допустимой индукции k_B (доля B_S при 100 °C) | `<0,65>` |
| Аддитивный допуск на индукцию u_B | `<3>` мТл |
| Предельный коэффициент заполнения окна k_зан | `<0,70>` |
| Минимальный запас по собственному резонансу k_R = f_res/f_sw | `<4>` |
| Допустимая плотность тока J_доп | `<2,5>` А/мм² |
| Коэффициент запаса по полю рассеяния k_СР | `<3>` |

## 7. Требования к отчёту

Итоговый отчёт — файл Word. Обязательно указать:
- парт-номер сердечника
- наименование провода обмотки со ссылкой на поставщика
- количество витков
- величину зазора
- запас по индукции и по току
- иные обязательные величины, указанные в методике

Оформление: `<ГОСТ Р 2.105 / без требований>`
Язык отчёта: `<русский>`

Обязательно указать, какие сердечники и материалы рассматривались и почему были отклонены —
с опорой на числа в сводной таблице.

Стилистика отчёта: `<новая / в той же стилистике, что файл ПУТЬ_К_make_report.py>`

## Приложение: как агенту переиспользовать базу знаний

[оставить как есть]

1. Прочитать `knowledge_base/components_db/*.json` — библиотеки сердечников, материалов и
   провода уже готовы, не собирать заново из даташитов.
2. Для статей читать `parsed.md`, а не PDF — текст уже извлечён.
3. Новые найденные статьи добавлять в базу по инструкции `knowledge_base/skills/SKILLS.md`,
   раздел «add-article».
4. Новые компоненты вносить в JSON по инструкции из раздела «update-db», сохраняя структуру
   полей и помечая непаспортные значения.
