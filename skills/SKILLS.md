# Рабочие процедуры базы знаний

## Расчёт дросселя

Основной переносимый навык находится в [inductor-design/SKILL.md](inductor-design/SKILL.md).

Он содержит:

- исправленную `.tex`-методику;
- автономный шаблон одиночного и interleaved boost-дросселя;
- конфигурацию ТЗ без проектных чисел в коде;
- полный перебор сердечников, материалов и литцендрата;
- генераторы рисунков и отчётов по исходному оформлению `drossel1/Backup`;
- автоматическую проверку JSON, количеств, рисунков, структуры отчёта и OOXML.

Создание и полный запуск нового проекта:

```powershell
python knowledge_base/skills/inductor-design/scripts/create_project.py <путь> --name <имя>
python knowledge_base/skills/inductor-design/scripts/run_pipeline.py <путь>
```

Обозначения не смешивать:

- `k_R = ℛ_g/ℛ_c = A_L0/A_L − 1` — отношение магнитных сопротивлений, минимальное значение задаёт `k_reluctance_min`;
- `k_f` — запас первой собственной частоты, значение задаёт `k_f_res`.

Предпочтительные семейства исходного технического задания: `EQ`, `ETD`, `PM`, `PQ`, `RM`, `EER`. Семейство `E` применяют только при отсутствии допустимого предпочтительного варианта после полного численного перебора. Записи `screened_out` сначала дополняют полными паспортными данными, если они прошли предварительный отсев.

## Поиск источника

Ищи по `bibliography.json`, не загружая всю библиографию:

```powershell
rg -i "<ключевое слово>" knowledge_base/bibliography.json
```

Для текста статьи читай `articles/<тема>/<источник>/parsed.md`. Формулы сверяй по PNG в `formulas/`, поскольку текстовый слой PDF теряет дробные черты, радикалы и интегралы.

## Добавление статьи

1. Создай `articles/<тема>/<Автор_Год_КраткоеНазвание>`.
2. Сохрани исходник как `source.pdf`.
3. Выполни:

```powershell
python knowledge_base/skills/parse_pdf.py <каталог_статьи>
python knowledge_base/skills/extract_formulas.py <каталог_статьи>
```

4. Добавь запись в `bibliography.json`.
5. Пересобери и проверь библиографию:

```powershell
python knowledge_base/skills/make_bibliography.py
python knowledge_base/skills/make_bibliography.py --check
```

## Обновление базы компонентов

Перед изменением сохрани копию изменяемого JSON в `knowledge_base/Backup/<дата>_<причина>`.

Для сердечника обязательны паспортные:

- геометрия `A_e`, `A_min`, `l_e`, `V_e`;
- параметры окна `A_N`, `l_N`, высота и радиальная ширина;
- масса и габариты комплекта;
- `A_L0` и каталожное обозначение для каждого допустимого материала;
- физическая площадь выбранной поверхности зазора `A_g` и источник размеров.

Для материала обязательны диапазон частот, `μ_i`, `B_S(T)`, температура Кюри, плотность, паспортная ссылка и коэффициенты потерь с областью применимости.

Для провода обязательны число и диаметр жил, площадь меди, наружный диаметр, температурный индекс, стандарт, поставщик и ссылка. Цена и наличие имеют дату и не используются как постоянный физический критерий.

Отсутствующий паспортный параметр записывай как `null`. Оценочные значения помечай `_estimated` и не подменяй ими паспортные ограничения. Исторические поля `status`, `notes` и `_meta.origin` не должны влиять на новый выбор.
