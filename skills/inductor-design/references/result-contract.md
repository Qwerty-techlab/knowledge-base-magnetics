# Контракт результатов и проверки

## 1. Конфигурация

`2_input_files/design_config.json` содержит снимок ТЗ для одиночного и interleaved-варианта. Частоты задаются массивом `f_sw_list`; расчёт и отчёт не должны предполагать ровно две частоты.

Допустимые значения текущего движка:

- `project.single_topology = single_boost_inductor_one_physical_gap`;
- interleaved — независимый дроссель каждой фазы;
- один физический зазор на магнитопровод.

## 2. JSON одиночного расчёта

`3_calc/results_single_gap.json` должен содержать:

- `meta`, `tz`, `materials`, `results`;
- для каждой частоты: статус, счётчики перебора, политику выбора, количества, предварительные таблицы, полный `core_material_table`, `material_comparison`, `selected`;
- в `selected`: `core`, `material`, `wire`, `mode`, `design`, `losses`, `margins`, `verification`.

## 3. JSON interleaved-расчёта

`5_interleaved/results_interleaved.json` должен содержать:

- `meta`, `tz`, `tz_derived`, `materials`, `results`;
- число фаз и фазные электрические параметры;
- для каждой частоты полный перебор, количества, выбранную фазную конструкцию, потери всей системы и незакрытые проверки.

## 4. Обязательные проверки

Валидатор должен завершаться ошибкой при любом условии:

- отсутствует частотный вариант или выбранная конструкция;
- число физических зазоров не равно единице;
- не выполнен инвариант количества комплектов и половинок;
- отсутствует полный перечень пар сердечник–материал;
- отсутствует численная причина отклонения;
- отчёт не содержит один из 13 разделов либо список источников;
- выбранные сердечник, материал, число витков или зазор не найдены в тексте отчёта;
- отсутствует обязательный PNG;
- `.docx` повреждён как ZIP/OOXML;
- в runtime-файлах шаблона осталась зависимость от `drossel1` или `Backup`.

Отсутствие внешнего конвертера PDF не является ошибкой расчёта, но должно быть явно сообщено, если пользователь запросил PDF.
