# Контракт расчёта

## 1. Приоритет источников

1. Исправленная `Metodika_VCh_silovykh_drosseley_bez_rascheta.tex`.
2. Заполненный `design_config.json` нового проекта.
3. Паспортные данные `knowledge_base/components_db`.
4. Расчётный код шаблона.

Старые отчёты и результаты не являются источником чисел.

## 2. Поддерживаемая схема

Расчётный движок поддерживает boost в режиме непрерывного тока. Interleaved-вариант содержит независимые одинаковые фазные дроссели. Один физический зазор расположен на центральном стержне каждого магнитопровода.

## 3. Обязательные различия коэффициентов

Отношение магнитных сопротивлений:

`k_R = ℛ_g / ℛ_c = A_L0 / A_L − 1 ≥ k_reluctance_min`.

Запас по первому собственному резонансу:

`f_рез ≥ k_f · f_треб,max`, где `k_f = k_f_res`.

Никогда не используй `k_R` как отношение частот.

## 4. Перебор

Для каждого частотного режима выполнить:

1. расчёт электрических углов допусков;
2. предварительный отсев по произведению площадей и диапазону `N_B…N_w`;
3. полный перебор всех полностью описанных `core × material × litz × parallel × N`;
4. проверку индуктивности, насыщения, окна, плотности тока, температуры, магнитного сопротивления и резонанса;
5. построение фронта Парето по потерям, массе и собственной ёмкости;
6. выбор внутри заданного окна потерь с политикой предпочтительных семейств.

Для каждой пары сердечник–материал сохранить число рассчитанных и допустимых вариантов, лучший допустимый вариант либо ближайший отклонённый вариант и численную причину отказа.

## 5. Неполные сведения о сердечнике

Предварительный список `screened_out` не участвует в финальном полном переборе. Если предпочтительный типоразмер проходит предварительный отсев, расчёт нельзя завершать до добавления в базу официальных:

- `A_e`, `A_min`, `l_e`, `V_e`;
- геометрии окна и средней длины витка;
- площади физического зазора и источника размеров;
- `A_L0` и каталожных обозначений по допустимым материалам;
- массы комплекта и габаритов.

## 6. Ограничения и статусы

- `u_B_num = null` до исследования сеточной сходимости МКЭ.
- Предел обмотки равен минимуму из заданного температурного предела и температурного индекса провода.
- Плотности тока `j_prelim` и `j_final_max` берутся только из конфигурации.
- Зазор изготавливается по целевому `A_L`, не по расчётному `g` без доводки.
- Итоговый статус до проверок: `analytical_preliminary`.

## 7. Инварианты количества

Один отдельный дроссель содержит один комплект из двух половинок. Для `n_phases` независимых дросселей требуется `n_phases` комплектов и `2 · n_phases` половинок. Частотные альтернативы не суммируются.
