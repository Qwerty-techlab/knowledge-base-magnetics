# База знаний: силовая электроника и магнитные элементы

Хранилище статей, баз данных компонентов и рабочих процедур для расчёта силовых
высокочастотных дросселей и преобразователей.

Смысл базы — один раз разобрать источник или даташит и больше к этой работе не возвращаться.
Текст статей уже извлечён, параметры компонентов уже собраны.

## Что внутри

| Путь | Содержание |

## Быстрый старт

Найти источник по теме:

```
grep -i "выпучивание" bibliography.json
```

Затем читать `articles/<topic>/<slug>/parsed.md` — **не** PDF.

Добавить статью:

```
mkdir articles/03_inductor_design/Автор_Год_Тема
cp статья.pdf articles/03_inductor_design/Автор_Год_Тема/source.pdf
python skills/parse_pdf.py articles/03_inductor_design/Автор_Год_Тема
# затем добавить запись в bibliography.json и:
python skills/make_bibliography.py
```

Проверить целостность базы:

```
python skills/make_bibliography.py --check
```

## Соглашения

- **PDF не в git** (`.gitignore`). В репозитории — только `parsed.md` и `metadata.json`.
  Исходные PDF лежат локально; их источник указан в `metadata.json`.
- Папки, начинающиеся с `_`, — служебные, в библиографию не входят.
- Отсутствующий параметр — `null`, не выдуманное число. Расчётные значения помечаются
  суффиксом `_estimated`.
- `title_source` в библиографии: `sources_md` и `pdf_metadata` — выверено,
  `derived_from_filename` — заголовок восстановлен по имени файла и **не** выверен
  (10 записей из 37).

## Происхождение

База собрана из проекта `drossel1` — расчёт дросселя трёхфазного interleaved boost
преобразователя 6 кВт, 160 → 235 В, 100/150 кГц. Оттуда взяты все 37 статей,
библиотеки компонентов и отработанный порядок расчёта.

Полный набор параметров сердечников и материалов проверен на реальном расчёте: выбран
магнитопровод PM 114/93 (TDK B65733, материал N27), обмотка литцендратом 500×0,071 мм
в 5 параллельных пучков.

## Ограничения

- Коэффициенты Штейнмеца подогнаны по паспортным кривым при 100 °C по 2 точкам на материал.
  За пределами указанного диапазона частот экстраполяция не гарантирована.
- Модель потерь не учитывает постоянное подмагничивание — для дросселя boost с большим
  I_dc это занижение потерь (см. `Sanusi_2023_DC_Bias_Impact_Core_Losses`).
- Цены литцендрата на август 2026, розница, один поставщик.
- В `articles/06_textbooks_ru` один учебник частично скан — текст извлечён неполно.
